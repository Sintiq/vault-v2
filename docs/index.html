Vault V2 0.1.0

A local-first personal archive for Windows with an Android companion. Free and voluntary.

Download the release · Installation and safety notes · Source

The Windows installer includes the signed phone companion. Official Tailscale accounts/apps are needed for phone pairing; follow the setup wizard.

No paid Windows Authenticode certificate: Windows may show an unknown-publisher warning. Do not disable protection. Updates require your approval. Local document work uses separately installed Ollama; an explicitly selected cloud fallback is not local-only. Back up important data.
